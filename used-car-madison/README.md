# 麦迪逊二手车捡漏报告（持有 2026-10 → 2027-08）

> 数据截至 **2026-09-30**。场景：住在 Madison（Dane County），预算约 $13,000，偏好雷克萨斯、路虎、丰田，开约 10.5 个月、约 9,000 英里后，明年 8 月卖掉。
> 所有金额单位为美元。“净成本”指持有期间真实花掉的钱，计算方式为：买价 + 税费 + 保险 + 油费 + 保养维修预留 + 冬胎 − 明年 8 月卖车收回的钱。
> 计算器是 [`tco.py`](tco.py)，输出见 [`tco_output.md`](tco_output.md)。原始调研数据在 [`data/`](data/)。

## 0. 结论先看

1. **路虎直接排除。** 10.5 个月净成本约 $9,600–12,000，是丰田或雷克萨斯（$5,000–6,500）的约 2 倍。主要原因：
   - 油耗约 14 mpg，而且要加 91 高标号油；
   - 维修尾部风险大：空气悬挂、5.0 V8 正时链一坏就是 $3,000–6,000；
   - 残值差：车行收车价只有私卖价的 52–60%。
2. **影响成本的第一大因素是买卖渠道，不是车型。** 同一台车按零售价从车行买、再卖回车行，要比“私人买（或车行低于市价买）+ 明年 8 月私人卖”多花约 $2,000–4,500。明年 8 月一定要自己私卖，卖给车行只当保底。
3. **不同车型的保险差别不大，差别主要在驾驶人条件。** 有 3 年以上美国驾照的人和刚来美国的新司机，保费差约 1.4 倍（10.5 个月差约 $500–700）。买车前先按 VIN 报价。
4. **本次核实过、最值得马上联系的车**（明细见第 1 节）：
   - **性价比首选：T6 2013 Toyota RAV4 XLE AWD，133k 英里，$12,050（已含车行费），Golden Cars，Madison 本地。**
     - 四驱，保险最便宜，明年 8 月最好卖；
     - CarGurus 评为 “Great Deal”，CARFAX 摘要显示无事故；
     - 预计净成本约 **$6,200**（折合约 $590/月，含保险和油费）。
   - **雷克萨斯首选：L4 2013 Lexus RX 350 AWD，98.7k 英里，Stark on the Beltline（Madison/Marshall）。**
     - 这是找到的里程最低、年份最新的 RX，就在本地；
     - **价格没查到，需要电话问**；
     - 开价 ≤ $12,500 时净成本约 **$6,100**，是雷克萨斯里最划算的；超过 $13,500 就放弃。
   - **最省钱：T1 2013 Toyota Prius，82k 英里，$9,795，Cottage Grove。**
     - 需先确认车还在；
     - 预计净成本约 **$5,500**，油费只有 SUV 的一半。
   - **芝加哥便宜雷克萨斯：L10 2012 Lexus ES 350，158k 英里，$8,812（已含费用），Napleton River Oaks Kia，Lansing IL。**
     - CarGurus 评为 “Great Deal”，车行在 CarEdge 的透明度评级为 A；
     - 净成本约 **$6,500**。
5. **如果能等：** 二手车价格 11 月到次年 2 月最低，1 月的“好价”数量比平均多 56%。10 月买可以接受，但千万别在 6–7 月买。明年 **8 月卖正好是卖方季节**，赶上新生来校。

## 3. 成本假设明细（都能在 `tco.py` 顶部修改）

### 3.1 买车税费（Madison 居民）

| 项目 | 金额 | 说明 |
|---|---|---|
| 销售税 | **5.5%**（州 5% + Dane County 0.5%） | 按车停放地计税，不按购买地。在 Milwaukee 或芝加哥买也交 5.5%；私人交易在 DMV 过户时交 |
| 过户费（Title） | **$214.50** | 2025 年 10 月起上调 $50 |
| 年度注册 | $85 + Madison 车轮税 $40 + Dane County 车轮税 $40 = **$165/年** | 混动车另加 $75/年；**卖车时不退、不按月折算** |
| 新车牌 | $12 | 2026 年 4 月起收费 |
| 临时牌 | 私人交易 $3；WI 车行免费 | |
| WI 车行服务费（doc fee） | 无上限：Smart $299、Bergstrom 和 Zimbrick $399、Lexus of Brookfield $479 | **可以谈低**，而且要算进应税价 |
| IL 车行 doc fee | 2026 年上限 **$377.63** | IL 车行对 WI 居民不收 IL 税（填 ST-556 / ST-588），但**要出示外州驾照**；没有 WI 或美国驾照可能被收 IL 税 |
| 尾气检测 | Dane County **不需要** | |
| PPI（第三方车检） | $100–250 | **一定要做** |

预算线：
- 从 WI 车行买（服务费 $399），要落地价 ≤ $13,000，车价需 ≤ **$11,550**；
- 私人买，车价需 ≤ **$11,950**。

### 3.2 保险（Madison，10.5 个月）

- **A 类**（22–28 岁、美国驾照 3 年以上、无事故），全险年费：
  - RAV4 约 $1,430；RX 约 $1,620；Camry / Corolla 约 $1,650；Prius 约 $1,700；ES 约 $1,720；
  - Range Rover Sport 约 $2,100。
- **B 类**（刚来美国、外国驾照或新考 WI 驾照）：约为 A 类的 1.4 倍。
- 威斯康星法定最低：责任险 25/50/10 加未投保驾驶人险（UM）25/50。**建议责任险买到 100/300/100**。
- **一定要买 comprehensive（综合险）**，它赔撞鹿。WI 撞鹿概率 1/62，全美第三高；Dane County 撞鹿事故数全州第四；10–12 月是高峰。
- 车值 < $8,000 时，可以只保 liability + comprehensive、不买 collision（碰撞险），保费约为全险的 56%。
- 中国大陆驾照：大陆不是日内瓦公约缔约国，**大概率要考 WI 驾照**。
- 可以承保外国驾照的保险公司：Progressive、State Farm（需找代理）、GEICO 等。
- 可用折扣：好学生折扣（最高 15–25%）、State Farm Drive Safe & Save（最高 30%，只降不升）。
- WI 法规 Ins 6.10(4)：卖车时**退保按天折算退款**。事先让保险公司书面确认 pro-rata。

### 3.3 油费

- 实际油价：2026 年 9 月 Madison 普通油 $4.03–4.46。
- 计算假设（持有期均价）：普通油 **$3.80**、高标号油 **$4.70**（EIA 预测 2027 年回落到 $3.35 左右）。
- 冬季油耗折扣：按 EPA 综合油耗 × 0.92 计。
- 9,000 英里油费：

  - ES 350 约 $1,550–1,690；RX 350 约 $1,860；
  - GX 470 约 $3,070；LR4 约 $3,280。
- 高油价情景（$4.40 / $5.30）：每台车多约 $200–500。

## 5. 看车与验车清单

**通用：**
- 用 CARFAX 或 AutoCheck 查 VIN。AutoCheck 可以 $49.99 买 25 份，适合多台对比。
- NICB VINCheck 免费。
- 核对三处 VIN 一致：仪表台、门框、title。
- title 上必须是卖家本人名字，不能是 open title；有贷款的要有 lien release。
- 看底盘锈蚀：门槛、轮拱、副车架、刹车油管。

**分车型重点：**

| 车型 | 检查重点 |
|---|---|
| **RAV4 2013–15** | 四驱耦合器和后差速器油是否换过；低速有无液力变矩器抖动；后排安全带召回是否已做 |
| **RX 350 2010–13** | 2GR 机油冷却器胶管是否已换成金属管；正时盖渗油；水泵；AWD 分动箱漏油；冷启动凸轮 VVT 异响 |
| **ES 350 2007–12** | 仪表台发黏或融化（厂家更换计划已于 2026-01 截止）；水泵；2007–09 年款的 VVT 油管 |
| **Prius / CT 200h** | 混动电池健康度（Dr. Prius 或店里检测）；EGR 冷却器积碳导致缸垫损坏；逆变器水泵；三元催化被盗 |
| **Corolla 2014+** | CVT 顿挫（通常刷程序即可解决） |
| **路虎** | 不建议买 |

**防骗：**
- 不付定金，不电汇，不信“人在外地、托运”这类说法。
- 价格低于市价 50% 的多是首付诱饵或骗局。
- Marketplace 见面约在警局的交易区（Madison 有过多起 Marketplace 约见抢劫）。
- WI 曾破获团伙倒改约 70 辆车里程，大约 450 万英里。**一定要对比 CARFAX 的历史里程**。

## 6. 购买流程提示

- **WI 私人交易：**
  - 卖家签 title；
  - 买家在 2 个工作日内挂上临时牌；
  - 可在 eMV Public 网上办理，但**需要 SSN 后四位**；没有 SSN 就去 DMV 现场办（柜台费 $5）；
  - 当场交 5.5% 税。
- **IL 车行：**
  - 出示外州驾照，签 ST-588，免 IL 税；
  - 办 IL 7 天临时牌（$10）或 WI 临时牌开回；
  - 回 WI 后交 5.5% 税并办 title。
- **WI 车行：**
  - 必须提供 Wisconsin Buyers Guide 和车检披露；
  - 服务费必须写明“not required by law”，可以谈低。

## 7. 小红书 / Marketplace 捡漏方法

- **最佳时机：**
  - 5 月毕业季和 12 月中旬，回国学生急售；
  - 11 月到次年 2 月车价最低。
- **渠道：**
  - 小红书内搜：“麦迪逊 出车”“Madison 出车”“UW 出车”；
  - UW CSSA 论坛二手版；
  - Craigslist Madison 的 by-owner 频道；
  - 芝加哥西北郊（Buffalo Grove、Schaumburg、Lemont 等）私人雷克萨斯车源最多，而且 Madison 私人报价常比芝加哥贵。
- **车行里的“捡漏”位置：**
  - 独立车行在 CarGurus 标 “Great Deal”、挂牌超过 60 天、价格刚降过的车；
  - 大品牌 4S 店收来的高里程置换车（通常急着出）。
- **信号：** 美国买家过度看重里程，保养好的高里程丰田或雷克萨斯常被低估。持有 10 个月、再加 9,000 英里，对残值影响很小。

## 8. 方法与局限

- **流程：**
  - 5 个研究 agent 查成本：税费、保险、油价和保养、残值、可靠性；
  - 约 14 个 agent 检索车源：按品牌、区域、私人渠道分工，共约 800 次搜索，收集约 300 条原始车源；
  - 8 个 agent 逐台核实 33 台候选车：用 VIN 交叉检索、查卖家口碑、对比市价；
  - 最后由对抗式审计 agent 复核首选车源和计算假设。
- **局限：**
  - 本环境的网络策略屏蔽了 Facebook、Craigslist、小红书和各车行网站，只能用搜索引擎的摘要；
  - 小红书基本没有被搜索引擎收录；
  - 保险为模型估算，误差约 ±30%，务必自己拿报价；
  - 残值为基于市场数据的估算，市场整体 ±5% 的波动约影响每台车 ±$500。
